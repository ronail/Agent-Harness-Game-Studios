# Antigravity Entry Point

This repo is a Claude Code-first game studio framework with Codex and Hermes
harness support. In Antigravity, skills live in `.agents/skills/` (symlinked to
`.claude/skills/`), custom subagents in `.agents/agents/` (generated — see
`.agents/README.md`), and rules in `.agents/rules/`.

Canonical instructions: `AGENTS.md` (harness spawning), `CLAUDE.md`
(collaboration protocol), `.claude/docs/coordination-rules.md`.
Model tiers → Gemini models: `.agents/agent-models.toml`.
Onboarding: `/start antigravity`.
